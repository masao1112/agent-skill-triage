# Third-party materials

The MIT license applies to the application source and original synthetic examples.
It does not relicense model weights, adapters, dependencies, research documents,
or imported skill packages. Those remain governed by their respective owners.

- Base model: `Qwen/Qwen3-0.6B`; preparation downloads its README and LICENSE.
- Fine-tuned adapter: supplied separately by the user. Model code is not a substitute
  for an adapter; a fresh clone needs a compatible trained checkpoint and tokenizer.
- Local fixtures: ignored under `samples/local/`; provenance is retained locally.
- Dependencies: see `requirements.txt` and their upstream licenses.

Models, imported datasets, local settings, reports and research PDFs are excluded
from Git by default. Review distribution rights before sharing any such assets.
